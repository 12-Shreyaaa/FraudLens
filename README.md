# FraudLens

A Real-Time Transaction Fraud Detection Platform built using Graph Algorithms, Sliding Window techniques, and Anomaly Detection.

## Features
- High Value Transaction Detection
- Fraud Ring Detection
- Rapid Transaction Detection
- Amount Spike Detection
- Interactive Dashboard (Coming Soon)
- CSV Upload (Coming Soon)

## Tech Stack
- Java
- Spring Boot
- React
- MySQL
- Tailwind CSS
